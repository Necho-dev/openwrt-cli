Remote OpenWrt admin over SSH or LuCI/ubus HTTP. Same services power the CLI tables, setup wizard, and full-screen TUI.

One-liner
curl -fsSL https://raw.githubusercontent.com/Necho-dev/openwrt-cli/main/install.sh | bash copy
PowerShell / cmd
pip install git+https://github.com/Necho-dev/openwrt-cli.git copy

From a clone: run install.bat. Then: openwrt setup

TUIOverview · Network · Neighbors · Services
doctorSSH / HTTP health, JSON-ready
networkInterfaces · Routes · Rules · Neighbors
setupLanguage + connection wizard
SSH / HTTPLuCI ubus when SSH is off
-f jsonAgent-friendly, no TTY needed
After install
openwrt setup # language + connection
openwrt doctor
openwrt tui
openwrt network neighbors

Config lives in ~/.openwrt-cli.yaml. Command names stay English; UI follows -L zh / -L en or the system locale. Python >= 3.12.
